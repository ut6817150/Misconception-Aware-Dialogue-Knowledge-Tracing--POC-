{problem}

== THE GENERAL MISCONCEPTION TO TRACK (the construct you label) ==
{profile}

Track ONLY this general misconception. The student may make other mistakes; those are not this misconception and must not be labelled present.

== DIALOGUE ==
{dialogue_block}

== LABELS, WITH GUARDS ==
- "present": the turn genuinely exhibits or relies on THIS general misconception. Do NOT label present just because the turn is wrong for some other reason, just because the student seems unsure, or just because the misconception appeared earlier. The faulty reasoning of this specific misconception must actually be in this turn.
- "absent": the student engages the reasoning this general misconception corrupts and does it correctly. Do NOT label absent for turns that simply don't involve the misconception's reasoning (those are not_evidenced).
- "not_evidenced": the turn does not engage the general misconception's reasoning at all (acknowledgement, clarifying question, restating, off-topic, or correct work on an unrelated part). When in doubt between absent and not_evidenced, ask whether the student actually did the specific reasoning the misconception is about; if not, it is not_evidenced.

Common mistakes to avoid:
- Labelling a turn present because the student is wrong, when they are wrong for a different reason than this general misconception.
- Labelling a turn absent when the student did not actually engage the misconception's reasoning (should be not_evidenced).
- Carrying a "present" forward to later turns where the misconception no longer appears.

== OUTPUT ==
Reason briefly per turn, then output ONLY a JSON object keyed by turn number (string), each value {{"label": ..., "reason": ...}}. No markdown or text around the JSON.
