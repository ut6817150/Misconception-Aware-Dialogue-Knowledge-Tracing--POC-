== THE GENERAL MISCONCEPTION TO TRACK (the construct you label) ==
{profile}

Track the general misconception only. Do not label other errors the student makes unless they are this misconception.

== DIALOGUE ==
{dialogue_block}

== HOW TO LABEL EACH STUDENT TURN ==
Assign exactly one label per numbered student turn:

1. "present" - The student's reasoning in this turn exhibits or depends on the general misconception. A turn is present even if the final number happens to be right, as long as the faulty reasoning is there. If the student is partway through correcting it but still relies on it at all, label present.

2. "absent" - The student engages exactly the reasoning the general misconception corrupts, and gets it right, showing no trace of the faulty idea. The key test: the misconception had a genuine OPPORTUNITY to appear in this turn (the student worked on the thing it is about) and it did not.

3. "not_evidenced" - The turn does not touch the reasoning the general misconception is about. Examples: the student acknowledges the tutor ("ok, I see"), asks a clarifying question, restates the problem, or talks about something unrelated. The misconception had NO opportunity to appear because the turn is not about that reasoning.

The hardest distinction is absent vs not_evidenced. Use this rule: if the student actively did the kind of reasoning the general misconception corrupts and got it right, it is absent. If the student did not do that reasoning at all in this turn, it is not_evidenced. A turn can contain correct work and still be not_evidenced if that work is not about the misconception's target.

== OUTPUT ==
First reason through the dialogue turn by turn. Then output ONLY a JSON object as the final answer, keyed by turn number (as a string), each value an object with "label" (one of present, absent, not_evidenced) and a brief "reason". No markdown, no text around the JSON. Example:
{{"1": {{"label": "absent", "reason": "correctly identifies the relevant quantities, the thing the general misconception corrupts"}}, "3": {{"label": "present", "reason": "still includes the irrelevant figure, an instance of the general misconception"}}}}
